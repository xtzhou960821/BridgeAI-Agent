# BridgeAI-Agent

BridgeAI-Agent 是面向交通基础设施巡检与病害检测的行业级 AI Agent 平台设计项目。

本仓库当前主要沉淀项目 V1.0 设计文档，覆盖项目背景、总体架构、Agent 总体设计、Tool SDK、Workflow 与任务编排、BridgeAI Platform、工程应用体系，以及 BridgeAI-Site 智慧工地平台方案与第一阶段 PRD。

## 目录结构

```text
.
├── agent/       # Agent 模块预留目录
├── backend/     # 后端服务预留目录
├── docs/
│   ├── md/      # Markdown 设计文档
│   ├── docx/    # Word 版本设计文档
│   └── ai-agent-workflow-infographic.png
├── examples/    # 示例与演示材料预留目录
├── frontend/    # 前端应用预留目录
└── tools/       # Tool SDK 与工具实现预留目录
```
