# BridgeAI-Agent V0.2 本地运行说明

本说明对应第一轮开发分支 `codex/v0.2-engineering-skeleton`，目标是验证工程骨架，而不是启动完整生产系统。

## 已验证命令

```bash
python -m pytest -v
```

该命令会验证当前纯 Python 核心：

- Tool SDK 注册、必填输入校验和执行结果；
- Workflow 状态推进、失败和恢复；
- Agent Runner 最小任务循环；
- 后端 Health payload。

## 后端启动

当前仓库未强制安装 FastAPI。安装后可启动后端入口：

```bash
python -m pip install -e ".[backend,dev]"
python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

健康检查路径：

```text
GET /api/v1/health
```

建议使用 `python -m uvicorn`，这样可以确保调用的是当前虚拟环境中的 Uvicorn，而不是 Anaconda 或系统环境中的全局命令。

## 前端启动

进入前端目录并安装依赖后启动：

```bash
cd frontend
npm install
npm run dev
```

当前前端为 V0.2 占位工作台，展示任务列表和任务详情占位，后续再接入真实 API、Workflow 事件流、病害复核和报告能力。

## 数据库迁移占位

首个迁移文件位于：

```text
backend/app/repositories/postgres/migrations/0001_v0_2_skeleton.sql
```

该迁移只创建最小任务表，用于后续本地冒烟和数据库迁移入口验证。

## 样例任务

样例任务位于：

```text
examples/v0_2_sample_task.json
```

它对应当前 Agent Runner 测试中的最小桥梁巡检任务：读取一个 Artifact，并调用 `image_quality_check` 示例 Tool。
